## Overview

QuickQuote helps you prepare straightforward job quotes in a browser. Its interface brings together customer details, materials and labour costs, saved quotes, and a printable quote preview.

## Features

- **Client address book** — add, select, and manage customer details.
- **Quote creation** — enter a job description with materials and labour amounts.
- **Saved quotes** — return to previously created estimates.
- **Print-friendly preview** — prepare a quote for printing.
- **Local browser storage** — save information in the browser used for the app.
- **Backup controls** — use the included backup section to protect stored information.

## Open the application

Open [`Index.html`](./Index.html) in a compatible browser, or use the project's own hosting/deployment arrangements when available. This repository contains a browser-based app; **no Android APK or Windows installer is published as a GitHub Release here**.

> **Your data:** Saved clients and quotes are stored in the browser. Use the app's backup controls before clearing browser data or changing devices.
